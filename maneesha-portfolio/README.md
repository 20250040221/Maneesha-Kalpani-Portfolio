# Maneesha Rathnayake — Personal Portfolio

A responsive personal portfolio served by Express.

## Run locally

```sh
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). Set the `PORT` environment
variable to use another port.

## Profile photo

Use the camera button on the profile photo to select a JPG, JPEG, PNG or WEBP
image up to 2 MB. The browser previews the image immediately; after the upload
succeeds, Express saves it in `public/images` so it remains available after a
refresh.
